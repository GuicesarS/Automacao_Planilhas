# Automação de Planilhas

Este repositório contém uma série de automações feitas para manipulação e correção de dados em planilhas, utilizando C# e algumas bibliotecas específicas. O objetivo deste projeto é facilitar a manipulação de dados em planilhas de forma automatizada, otimizando processos e corrigindo erros comuns de forma eficiente.

## Como isso é importante para a empresa ?

As automações desenvolvidas neste projeto ajudam diretamente na otimização do tempo e na redução de erros operacionais. Ao substituir tarefas manuais por processos automatizados, é possível:

- Aumentar a produtividade da equipe.
- Minimizar falhas humanas em atividades repetitivas.
- Garantir maior consistência e integridade dos dados.
- Entregar relatórios e análises com mais agilidade.
- Reduzir o retrabalho e os custos operacionais.

Essas soluções tornam o fluxo de trabalho mais eficiente e profissional, permitindo que a equipe foque em atividades estratégicas em vez de rotinas repetitivas.

## Estrutura do Projeto

O projeto está organizado da seguinte forma:

### 1. **Pasta: Planilha**
   - **Descrição**: Contém as planilhas utilizadas nas automações. Aqui você encontrará os arquivos de planilha (.xlsx, .csv) que são manipulados pelos scripts.
   
### 2. **Pasta: Corrigir Coluna**
   - **Descrição**: Contém o programa que corrige uma coluna com defeito nas planilhas. Este script busca por valores incorretos ou formatos inconsistentes e os corrige de acordo com as regras definidas.
   - **Objetivo**: Automatizar a correção de colunas com dados errôneos.

### 3. **Pasta: Script Padrão para Criar Planilha **
   - **Descrição**: Um script padrão utilizado para criar planilhas no formato `.xlsx` utilizando o C#. Este script pode ser reutilizado sempre que for necessário criar uma planilha com estrutura básica e dados dinâmicos.
   - **Objetivo**: Facilitar a criação e exportação de planilhas no formato desejado.

### 4. **Pasta: Manipulação de Dados**
   - **Descrição**: Scripts para manipulação de dados dentro das planilhas. Essa parte do repositório contém automações que fazem cálculos, filtros, e outras operações de processamento de dados diretamente nas planilhas.
   - **Objetivo**: Realizar operações automatizadas de transformação e análise de dados em planilhas.

### 5. **Pasta: Planilha de Estudo**
   - **Descrição**: Planilha usada para estudos, com o intuito de absorver conceitos e técnicas de manipulação de dados e automação em planilhas.
   - **Objetivo**: Arquivo de aprendizado e experimentação para testar novos métodos e técnicas.

### 6. **Pasta: Tarefas da Empresa**
   - **Descrição**: Scripts e automações desenvolvidas para otimizar tarefas. Estas automações incluem a organização de dados, processamento e relatórios baseados em informações extraídas de planilhas.
   - **Objetivo**: Automatizar tarefas repetitivas e melhorar a produtividade no ambiente de trabalho.
